# DNS Notify

**Know before the client does.**

A server can be healthy while visitors see “Your connection is not private”, “This site can’t be reached”, a parked domain or bounced email. DNS, the served certificate, domain registration and email records can fail outside the application stack.

[DNS Notify](https://dnsnotify.com/) watches those public signals from outside the provider account and alerts on meaningful changes. No AI analysis. No noise. No registrar or DNS provider login required.

- DNS record change monitoring
- SSL certificate monitoring
- Domain expiry monitoring
- MX, SPF, DKIM and DMARC monitoring

Built for web agencies, designers, developers and MSPs who would rather know first than take an urgent call from a client. £5 per month or £50 per year covers five domains.
